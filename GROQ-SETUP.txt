PLAYROOM 3.0 — GROQ EDITION

The website and games are unchanged. Only netlify/functions/ai.js has been switched to Groq.

1. In your GitHub repo, replace netlify/functions/ai.js with the file in this ZIP.
2. In Netlify > playroomapi > Environment variables, set GROQ_API_KEY to your GroqCloud API key. Set scope to Functions (or All scopes). Do not put it in GitHub or index.html.
3. Redeploy your site, then test the PLAYROOM AI chat.
4. Optional: set GROQ_MODEL to a currently available Groq chat model. Default: openai/gpt-oss-20b.

Groq free-tier limits apply. Publicly exposing a chat endpoint may exhaust your free quota; add abuse/rate limiting before sharing widely. An eligible adult should handle API account setup if required.

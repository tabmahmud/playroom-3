PLAYROOM — Embedded Games Edition

Replaced the four custom games in the visible library with one externally hosted game: Fastlane: Road to Revenge. The provided iframe URL and DooDoo.Love attribution are preserved. The original custom game script remains in the bundle but its game cards have been removed.

To deploy: upload these files to the GitHub repository root connected to Netlify. Keep GROQ_API_KEY set only in Netlify Environment Variables. No new API key needed.

The embedded game loads from html5.gamemonetize.co; its availability, advertisements, and iframe behavior depend on that external host. Verify that the publisher allows your intended use.
